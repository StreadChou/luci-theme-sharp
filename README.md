# Sharp

Sharp 是一款独立开发的 OpenWrt LuCI 主题，采用简洁的顶部导航与直角布局，支持浅色、深色及跟随系统的外观，适配桌面和手机。

[安装](#安装) · [设置项](#设置项) · [效果展示](#效果展示) · [文档](docs/README.md)

## 安装

### 适用环境

当前面向 **OpenWrt 25.12 的 Ucode 版 LuCI**，路由器需已安装 LuCI。旧版 Lua `.htm` 主题环境不在支持范围内。

从 [GitHub Releases](https://github.com/StreadChou/luci-theme-sharp/releases/latest) 下载 `luci-theme-sharp` 的 `.apk` 安装包，确认固件符合对应版本的发布说明。官方发布包不依赖 CPU 架构，简体中文已包含在主题包中。需要自行生成安装包时，参阅[软件包构建](docs/BUILD.md)。

### 安装主题

将 `.apk` 安装包上传到路由器的 `/tmp/` 目录，通过 SSH 登录路由器后执行：

```sh
apk update
apk add --allow-untrusted /tmp/luci-theme-sharp-*.apk
```

上述命令适用于使用 APK 的目标固件；目录中只保留本次要安装的 Sharp 安装包。`--allow-untrusted` 允许安装未签名或签名尚未受信任的本地软件包。

安装脚本会注册并启用 Sharp。刷新 LuCI 页面；需要手动切换时，在 **系统 → 系统 → 语言和界面 → 主题** 中选择 **Sharp**，保存并应用。

简体中文翻译已随主题内置，无需安装单独的 Sharp 中文语言包。路由器运行主题不需要 Node.js 或编译器。

### 更新与卸载

更新时安装与固件匹配的新版软件包，再刷新页面。卸载前先在 **语言和界面** 中切换到其他已安装的主题，然后执行：

```sh
apk del luci-theme-sharp
```

## 设置项

### 外观

桌面端点击顶栏右侧的**外观图标**；手机端点击右上角的**设置图标**，在“外观”中选择：

| 选项 | 效果 |
| --- | --- |
| 浅色 | 使用浅色配色 |
| 深色 | 使用深色配色 |
| 跟随系统 | 根据设备系统的外观设置自动切换，默认选项 |

外观偏好保存在当前浏览器中，也应用于登录页。更换浏览器或设备后可分别设置。

界面动效跟随系统的“减少动态效果”设置；开启后，菜单和弹窗会直接切换。

桌面顶栏的**自动刷新按钮**显示 LuCI 当前轮询状态：刷新图标表示自动刷新中，点击暂停；暂停图标表示已暂停，点击恢复。它只控制页面数据的自动更新，不会重新加载整页。LuCI 未提供自动刷新控制时隐藏此按钮。

有未应用配置时，顶栏显示数量按钮；手机端位于搜索与设置图标之间。数量变化且不为 0 时，按钮下方会显示「你有 N 项配置尚未保存」的单条提醒。点击数量按钮或提醒文字都可打开 LuCI 原生的配置变更弹窗；点击提醒右侧的 X 可关闭。当前页面中，相同数量不会重复提醒，下一次数量变化时再次显示，归零时自动收起。桌面两种布局及手机端均支持。

### 界面语言

Sharp 跟随 LuCI 当前语言，内置英文和简体中文。在 **系统 → 系统 → 语言和界面 → 语言** 中调整，保存并应用后生效。其他插件的翻译由各自的语言包提供。

### Sharp 主题设置

**系统 → Sharp 主题设置** 提供「基础设置」「登陆界面」「主界面」三个子页面，默认进入「基础设置」。

「主界面」提供可点击的布局示意卡片：

| 设置项 | 选项 | 布局 |
| --- | --- | --- |
| 桌面端布局 | 默认(类OpenWrt) | 顶部一级导航和二级下拉菜单 |
| 桌面端布局 | 类argon | 左侧双层导航：一级菜单图标在上、文字在下，右侧显示二级菜单；三级页面标签位于 Header 下方 |
| 手机端布局 | 默认 | 顶部菜单按钮及纵向导航抽屉 |

点击桌面布局卡片立即切换，无需保存或刷新。选择保存在当前浏览器中，刷新、跳转页面后仍保留；其他浏览器或设备可分别设置。屏幕宽度不超过 900px 时使用手机布局，不受桌面布局选择影响。

「基础设置」可以修改 **Logo 和品牌文本**，用于登录页、桌面与手机页头。支持上传 PNG、JPEG、GIF、WebP 或 SVG 图片（最大 2 MB），也支持填写设备上 `/luci-static/` 或 `/www/luci-static/` 下的图片路径。上传图片会转换为 PNG，最大边长为 512 像素，动图使用静态画面。

页面提供实时预览和「恢复默认 Logo 和文本」。文本最多 32 个字符，留空使用 `SHARP`；图片路径留空使用内置 Logo，图片无法加载时也会回退。点击「保存并应用」后生效，设置保存在设备上，对所有浏览器共用；「保存」仅暂存，仍可撤销。系统备份包含上传的图片，恢复备份时随配置还原。

「登陆界面」提供以下设置，保存并应用后对所有浏览器生效；重新打开登录页即可看到效果：

登录面板使用独立的品牌区、欢迎标题和设备名称，输入框带有图标及聚焦提示。密码框右侧可切换显示／隐藏密码，居中卡片和经典侧栏使用相同的表单样式。

| 设置项 | 选项 |
| --- | --- |
| 登录框显示类型 | 居中卡片（默认）、经典左侧栏；窄屏侧栏自动占满宽度 |
| 背景 | 内置默认壁纸、纯色、必应每日壁纸、Wallhaven 风景图、自定义图片 |
| 背景图片 | 上传图片或填写本机 `/luci-static/`、`/www/luci-static/` 图片路径 |
| 图片显示方式 | 铺满屏幕（裁剪边缘）、完整显示图片 |
| 背景暗化 | 0～80%，默认 20% |
| 登录框不透明度 | 0～100%，默认 100% |
| 登录框背景模糊 | 0～30 px，默认 0 |

背景上传支持 PNG、JPEG、GIF、WebP 和 SVG，最大 10 MB、4000 万像素，转换为最大边长 2560 像素的静态 JPEG；动图取静态画面。页面提供实时预览和「恢复默认登录页外观」。内置壁纸随主题安装，无需联网。必应每日壁纸和 Wallhaven 风景图需要联网，来源不可用或图片加载失败时自动显示内置壁纸，登录操作不受影响；在线来源的图片地址在设备内存中缓存 12 小时。切换背景来源会保留自定义图片路径，便于再次启用。上传图片随系统备份保留。背景图片会在登录前公开显示，请选择适合公开的图片。Logo 和文本沿用「基础设置」，浅色／深色沿用当前浏览器的外观偏好。
