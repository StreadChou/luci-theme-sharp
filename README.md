# Sharp

Sharp 是一款独立开发的 OpenWrt LuCI 主题，采用简洁的顶部导航与直角布局，支持浅色、深色及跟随系统的外观，适配桌面和手机。

[安装](#安装) · [设置项](#设置项) · [效果展示](#效果展示) · [文档](docs/README.md)

## 安装

### 适用环境

当前面向 **OpenWrt 25.12 的 Ucode 版 LuCI**，路由器需已安装 LuCI。旧版 Lua `.htm` 主题环境不在支持范围内。

准备与目标固件版本和架构匹配的 `luci-theme-sharp` 安装包。需要自行生成安装包时，参阅[软件包构建](docs/BUILD.md)。

### 安装主题

将 `.apk` 安装包上传到路由器的 `/tmp/` 目录，通过 SSH 登录路由器后执行：

```sh
apk update
apk add --allow-untrusted /tmp/luci-theme-sharp-*.apk
```

上述命令适用于使用 APK 的目标固件；目录中只保留本次要安装的 Sharp 安装包。`--allow-untrusted` 允许安装未签名或签名尚未受信任的本地软件包。

安装脚本会注册并启用 Sharp。刷新 LuCI 页面；需要手动切换时，在 **系统 → 系统 → 语言和界面 → 主题** 中选择 **Sharp**，保存并应用。

简体中文翻译已随主题内置，无需安装单独的 Sharp 中文语言包。路由器运行主题不需要 Node.js 或编译器。

### 更新与卸载

更新时安装与固件匹配的新版软件包，再刷新页面。卸载前先在 **语言和界面** 中切换到其他已安装的主题，然后执行：

```sh
apk del luci-theme-sharp
```

## 设置项

### 外观

桌面端点击顶栏右侧的**外观图标**；手机端点击右上角的**设置图标**，在“外观”中选择：

| 选项 | 效果 |
| --- | --- |
| 浅色 | 使用浅色配色 |
| 深色 | 使用深色配色 |
| 跟随系统 | 根据设备系统的外观设置自动切换，默认选项 |

外观偏好保存在当前浏览器中，也应用于登录页。更换浏览器或设备后可分别设置。

界面动效跟随系统的“减少动态效果”设置；开启后，菜单和弹窗会直接切换。

有未应用配置时，顶栏显示数量按钮；手机端位于搜索与设置图标之间。点击可打开 LuCI 原生的配置变更弹窗。

### 界面语言

Sharp 跟随 LuCI 当前语言，内置英文和简体中文。在 **系统 → 系统 → 语言和界面 → 语言** 中调整，保存并应用后生效。其他插件的翻译由各自的语言包提供。

### Sharp 主题设置

**系统 → Sharp 主题设置** 当前保留空白页面，暂无配置项。外观切换请使用顶栏入口或手机设置弹窗。
