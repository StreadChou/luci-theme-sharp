# Sharp v0.2.0 · 主题设置与登录外观

本版对比上一标签 **v0.1.0**（`095db725dc831b675c0d1e05288f3920cc88f924`），增加品牌与登录外观设置、类 Argon 桌面布局，并改进顶栏的自动刷新和未应用配置提醒。主题继续保留 LuCI 原生页面、认证及保存、应用、撤销流程。

## 相比 v0.1.0 的变化

### 主题设置与品牌

- 原空白的「系统 → Sharp 主题设置」扩展为「基础设置」「登陆界面」「主界面」三个子页面，默认进入基础设置。
- Logo 和品牌文本可由设备统一配置，对登录页、桌面和手机页头生效。支持上传图片、本机静态图片路径、预览和恢复默认；留空或图片失败时回退内置品牌。
- 上传的 Logo 转换为最大边长 512 像素的 PNG，背景转换为最大边长 2560 像素的 JPEG；使用专用目录和新文件名，并加入系统备份。

### 主界面与顶栏

- 增加类 Argon 双层侧栏：一级菜单显示图标与名称，二级菜单显示在右栏；菜单继续来自 LuCI，三级标签显示在 Header 下方。
- 主界面设置提供布局示意卡片，可在顶部导航与侧栏之间立即切换；选择仅保存在当前浏览器，窄屏沿用手机导航。
- 自动刷新按钮改为控制 LuCI 原生轮询的暂停／恢复，图标跟随原生状态。
- 未应用配置数量变化时显示单条提醒，支持关闭及打开原生变更弹窗；兼容桌面两种布局、手机、焦点和弹窗互斥。

### 登录页

- 重设计品牌区、欢迎标题、设备名、带图标的输入框、主按钮和页脚；增加密码显示／隐藏切换，离开页面恢复掩码。
- 支持居中卡片和经典侧栏，设置面板不透明度、背景模糊、图片填充方式及暗化强度，并提供实时预览与恢复默认。
- 背景可选内置默认壁纸、纯色、必应每日壁纸、Wallhaven 风景图或自定义图片。默认壁纸随包安装，在线来源异步加载，失败自动回退，不阻塞登录。
- 在线壁纸只解析两个固定来源，具有域名校验、请求限时、并发锁及成功／失败缓存；缓存写入设备内存。

### 构建与维护

- 增加品牌、登录设置及壁纸解析的 14 项回归检查，原生 LuCI JS 纳入翻译提取和开发同步。
- 新增运行依赖 `wget-ssl`、`ca-bundle`、`jsonfilter`；扩展 APK 检查，覆盖新增设置模块、ACL、备份文件及壁纸脚本权限。
- 更新主题资源缓存标识、中文翻译、开发文档和 UI 改动报告。

## 安装与升级

适用于 **OpenWrt 25.12 的 Ucode 版 LuCI**，不支持旧版 Lua `.htm` 主题环境。流水线使用官方 OpenWrt 25.12.5 SDK，目标产物为架构无关的 `luci-theme-sharp-0.2.0-r1.apk`，并附带 `SHA256SUMS` 和 `package-metadata.txt`。

下载 APK 并上传到设备 `/tmp/` 后执行：

```sh
apk update
apk add --allow-untrusted /tmp/luci-theme-sharp-0.2.0-r1.apk
```

安装或升级后刷新 LuCI 页面。品牌和登录设置保存在设备的 `luci.sharp` 中，使用原生保存、应用与撤销；桌面布局和配色偏好保存在各自浏览器中。新版本默认使用居中登录卡片和内置壁纸，需要纯色背景时可在登陆界面设置中选择。简体中文随包提供。
