# Sharp v0.1.0 · 首次发布

Sharp 是一款独立开发的 OpenWrt LuCI 主题，以简洁的顶部导航、直角设计和清晰的内容布局为核心，支持桌面和手机。主题使用 Ucode 模板、原生 CSS 和 TypeScript，保留 LuCI 原生页面、权限以及保存、应用和撤销流程。

## 首版功能

- 桌面顶部导航、二级下拉菜单和基于真实 LuCI 菜单的搜索。
- 手机导航抽屉与快捷设置弹窗，适配窄屏布局。
- 浅色、深色、跟随系统三种外观，偏好保存在当前浏览器。
- 默认标签、原生标签和面包屑适配，表格与长内容局部滚动。
- 未应用配置数量提示，可打开 LuCI 原生变更弹窗。
- 内置英文与简体中文，界面语言跟随 LuCI。
- 支持键盘操作、可见焦点及系统的“减少动态效果”偏好。

## 适用环境与文件

- 面向 **OpenWrt 25.12 的 Ucode 版 LuCI**，需已安装 LuCI；旧版 Lua `.htm` 环境不在支持范围内。
- 本版使用官方 **OpenWrt 25.12.5 SDK** 构建，提供不依赖 CPU 架构的主题 APK。
- 下载 `luci-theme-sharp-0.1.0-r2.apk`；`r2` 是现有软件包修订号，项目版本为 `0.1.0`。
- `SHA256SUMS` 用于校验安装包，`package-metadata.txt` 记录包内容和元数据。
- 简体中文已包含在主题包中，路由器无需 Node.js 或编译器。

## 安装

从本 Release 下载 APK，上传至路由器 `/tmp/`，通过 SSH 执行：

```sh
apk update
apk add --allow-untrusted /tmp/luci-theme-sharp-0.1.0-r2.apk
```

安装脚本会注册并启用 Sharp，刷新 LuCI 页面即可。也可在 **系统 → 系统 → 语言和界面 → 主题** 中选择 **Sharp**，保存并应用。`--allow-untrusted` 用于安装尚未加入本机信任范围的本地软件包。

桌面端通过顶栏外观图标切换配色；手机端通过右上角设置图标进入快捷设置。**系统 → Sharp 主题设置** 当前保留空白页面，暂无配置项。

卸载前先切换到其他已安装的主题，再执行 `apk del luci-theme-sharp`。
